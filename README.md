# CM-PiLNN — Baseline-First Evaluation of Permutation-Induced Channel Decoupling for Parallel Liquid Neural Networks (π-CfC)

Technical Report 4 of the CM series. CfC (closed-form continuous-time) layers compute a nonlinear
recurrence, so their cost is Θ(L) sequential steps. The natural research move is to make most of the
state cheap: permute channels into a small **hot** set that keeps the full CfC update and a large
**cold** set that is linearised and advanced by a parallel associative scan. This repository builds
that architecture (π-CfC) and measures it against the baseline it is supposed to replace.

* Report: [`CM-PiLNN.pdf`](CM-PiLNN.pdf) · source [`paper/main.tex`](paper/main.tex) (18 pages)
* Audit: `python scripts/verify_all.py` → `results/verify_all.json` (**86/86 PASS**)
* Phase report: [`results/PHASE3_4_REPORT.md`](results/PHASE3_4_REPORT.md)

## What is established

| Claim | Evidence | Where |
|---|---|---|
| The permutation is an **exact** bilateral isomorphism | fp64 `1.0e-15`, fp32 `4.6e-7`; one-sided control `0.98–1.08` | `results/phase1_isomorphism.json` |
| The one-step Jacobian is strongly concentrated | Gini `0.74–0.92`; top-25% of channels hold 83–98% of the mass | `results/phase1_spectrum.json`, Fig. 1 |
| Accuracy is **conditional** on the hot fraction | parity `ρ=1/8` → `1.000` after DAFT (0.505 zero-shot); mod-3 needs `ρ≥1/4`; flip-flop `1.000` at `ρ=1/16` | `results/phase3_expressivity.json` |
| Trajectory error follows a two-sided amplification law | 13/15 cells inside `[ε√((1−ᾱ^{2T})/(1−ᾱ²)), ε(1−ᾱ^T)/(1−ᾱ)]` | Table 6, `results/phase3_expressivity.json` |
| Speedup is a **kernel-limited** regime, mapped exactly | best per-shape config `8.6–86.5×` vs the PyTorch loop, `7.3–45.4×` vs the best sequential baseline (incl. a single-launch Triton kernel) | `results/phase4_hardware.json` |
| It survives real data | WikiText bytes `2.882` BPD (unigram `4.579`); ten real CIF clips `R² 0.900`; ordering effect reproduces | `results/phase6_realworld.json`, Fig. 5 |

Three contiguous, disjoint regions (70/15/15, split inside every clip) separate training, ranking and
scoring, so **no approximation is measured on data it was fitted to**. The engineering log in §10 lists
fourteen defects that each changed a published conclusion, including the two that produced
"better than exact" numbers in earlier revisions.

## Layout

```
src/models.py            CfC layer, exact forward, associative scan, permutation, unpermutation
src/ordering.py          Jacobian step, residual scores, co-activation clustering, Gini/Pareto
src/tasks.py             synthetic tasks (oscillator, parity, multiscale) + RK4 integrator
src/neurtasks.py         non-TC^0 suite: Parity-Stream, Modulo-3 Counter, FlipFlop-Reset
kernels/triton_picfc.py  cold scan, single-launch sequential kernel (_seq_l2), L2-fused tiled hot kernel
kernels/avx512_picfc.cpp AVX-512 sequential + chunked scan + hot recurrence + fused single entry point
kernels/hybrid.py        ctypes bindings for the C++ kernels
scripts/phase1_*         training, isomorphism, spectrum
scripts/phase2_*         6 rules x 8 ρ x 3 checkpoints, scan gate
scripts/phase3_*         amplification law, ridge recalibration, non-TC^0 suite, GPU-accelerated refit
scripts/phase4_*         60-cell hardware sweep (GPU Triton + CPU AVX-512), gates, RSS probe
scripts/phase6_*         real-stream models (WikiText bytes, ten CIF clips) with the 70/15/15 protocol
results/                 every number in the report, as JSON; tables are generated from these
figures/                 the five report figures (PDF + PNG), generated by the scripts
```

## Reproduction

```bash
pip install torch triton numpy matplotlib
export OMP_NUM_THREADS=16 OMP_PLACES=cores OMP_PROC_BIND=close OMP_WAIT_POLICY=passive

python scripts/phase1_train_and_audit.py
python scripts/phase2_dynamical_equivalence.py
python scripts/phase3_expressivity_and_calibration.py amp|ridge|expr|osc
python scripts/phase3_ridge_gpu.py
python scripts/phase4_hardware_benchmarks.py full     # 60 cells, gated, RSS-probed
python scripts/phase6_realworld_benchmarks.py split|train|spectrum|gate|decouple|ridge|daft|hw|fig
python scripts/make_tables.py && python scripts/make_p6_tables.py
python scripts/verify_all.py                          # must print PASS
```

Data: Model D reads a WikiText-2 test byte stream; Model E reads ten real CIF clips decoded to
16×16 grey frames (`data/frames16_raw.npz`, 4 410 frames). Video frames are third-party content and are
not redistributed beyond the derived 16×16 grey array.
